# 视唱练耳 Web App 产品需求文档（PRD）

## 1. 文档信息

| 项目     | 内容                              |
| -------- | --------------------------------- |
| 项目名称 | Oh Your Ear（暂定名）             |
| 文档版本 | v0.3（精简版）                    |
| 目标平台 | Web（响应式：桌面 / 平板 / 手机） |
| 状态     | 待评审                            |

## 2. 产品定位

一款**开箱即用**的浏览器视唱练耳工具：

- 未登录即可使用全部基础练习；
- 登录后解锁学习计划、进度统计、错题本等长期能力；
- 覆盖单音、音程、和弦、旋律、节奏五大训练模块；
- 支持多语言与深色/浅色主题切换；
- 电脑、Pad、手机一致体验。

## 3. 目标用户

- 音乐爱好者
- 艺考/考级学生
- 乐理自学者

## 4. 核心原则

1. **零门槛使用**：打开网页就能练，不强制注册。
2. **实时随机出题**：每道题在浏览器端即时生成，选项带合理干扰。
3. **可重复听辨**：每道题支持无限次重放。
4. **登录增值**：高级数据功能仅对登录用户开放，吸引注册。
5. **全球化与个性化**：支持多语言（至少中英）与深色/浅色主题。

## 5. 功能需求

### 5.1 练习流程（所有模块通用）

1. 用户进入模块练习页；
2. 点击大播放按钮，系统生成并播放当前题目；
3. 播放结束后展示若干选项；
4. 用户选择答案，立即显示对错与正确答案；
5. 答错可收藏到错题本（登录后）；
6. 点击「下一题」进入新题；
7. 一轮结束后展示成绩小结。

### 5.2 模块一：单音（Single Note）

- 播放一个钢琴音，用户从选项中选出音名。
- 选项范围：C / C# / D / D# … B 共 12 个音名。
- 干扰项从剩余音名中随机抽取，优先音高相近。
- 可配置：音域范围、是否仅白键、选项数量。

### 5.3 模块二：音程（Interval）

- 播放两个音，用户选出音程名称（小二度至纯八度等）。
- 支持旋律音程（先后）与和声音程（同时），可单独或混合练习。
- 可配置：根音固定或随机、播放方式、选项数量。

### 5.4 模块三：和弦（Chord）

- 播放一个和弦，用户判断和弦性质。
- 首期支持：大三、小三、增、减、属七、大七、小七等。
- 和弦默认以原位柱式或分解方式播放。
- 可配置：启用哪些和弦类型、播放方式、是否显示根音提示（P2）。

### 5.5 模块四：旋律（Melody）

- 播放一段 3~8 个音的旋律，用户从候选旋律中选出正确的一条。
- 干扰项为与正确旋律有 1~2 个音差异的变体。
- 可配置：旋律长度、音域、播放速度。

### 5.6 模块五：节奏（Rhythm）

- 播放一段节奏型（打击乐采样，无音高干扰），用户选出对应的时值组合。
- 首期以「选择模式」为主：展示若干节奏图案，选出听到的那个。
- 可配置：拍号（2/4、3/4、4/4）、音符类型集合、小节数、BPM。

### 5.7 播放与重放

- 播放按钮为页面最突出操作，手机端拇指可达。
- 播放中显示状态动画或文案提示。
- 播放完成后可随时重放当前题目，重放不改变题目内容。
- 答错后可单独播放正确答案供对比。

### 5.8 题目生成规则

- 每道题实时随机生成，不依赖预置题库。
- 同一轮内不出现完全相同的题目。
- 干扰项与正确答案不重复，并按模块规则生成（如音程干扰项避免与正确答案度数相同）。

### 5.9 反馈与计分

- 答对：绿色高亮 + 正向反馈。
- 答错：红色高亮所选，绿色标出正确。
- 每轮默认 10 题，可配置 5 / 10 / 20。
- 小结页：正确数、正确率、用时、逐题回顾。

### 5.10 登录与高级功能

**登录方式（首期）**：邮箱验证码、Google 登录。

登录后解锁：

| 功能       | 说明                                                    |
| ---------- | ------------------------------------------------------- |
| 学习计划   | 设定每日题数/时长、重点模块，首页展示今日进度           |
| 进度统计   | 总练习量、正确率趋势、各模块能力分布                    |
| 错题本     | 自动/手动收藏错题，支持按模块筛选与错题重练             |
| 跨设备同步 | 学习记录、错题本、设置在登录账号间同步                  |
| 连续打卡   | 每日完成练习即打卡，展示连续天数                        |
| 成就徽章   | 完成里程碑任务获得徽章，如累计 100 题、音程正确率达标等 |

### 5.11 设置与个性化

| 设置项     | 说明                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 语言       | 多语言切换，首期支持简体中文、English；所有 UI 文案、提示、选项均走 i18n |
| 主题       | 浅色 / 深色 / 跟随系统，默认跟随系统，切换后持久化                       |
| 音量       | 全局播放音量滑杆                                                         |
| 每轮题数   | 5 / 10 / 20                                                              |
| 模块级设置 | 各模块独立配置音域、选项数、播放方式、节奏 BPM 等                        |
| 学习计划   | 仅登录后可用                                                             |

## 6. 登录策略

| 模式     | 权限                                             | 数据存储                         |
| -------- | ------------------------------------------------ | -------------------------------- |
| 游客     | 全部基础练习、基础设置、单轮成绩                 | 浏览器本地，换设备/清缓存丢失    |
| 登录用户 | 额外解锁学习计划、统计、错题本、同步、打卡、成就 | 云端持久化，本地缓存辅助离线使用 |

- 未登录时不阻断练习流程。
- 在「保存错题」「查看统计」「设置学习计划」等入口用非阻断方式提示登录。
- 登录成功后返回用户原先所在页面。

## 7. 界面与响应式

### 7.1 主要页面

1. **首页**：模块卡片、今日计划进度、登录入口、语言/主题切换。
2. **练习页**：返回、进度、设置、大播放按钮、选项区、下一题。
3. **小结页**：成绩、逐题回顾、再来一轮、返回首页、登录后查看详细统计。
4. **我的（登录后）**：学习计划、统计、错题本、成就、账号设置。

### 7.2 响应式断点

| 断点               | 布局要点                                             |
| ------------------ | ---------------------------------------------------- |
| ≥1024px（桌面）    | 内容居中最大宽度约 900px，模块卡片 3 列，选项 2~3 列 |
| 768–1023px（平板） | 模块卡片 2 列，选项 2 列                             |
| <768px（手机）     | 单列，底部固定主操作按钮，单手可达                   |

### 7.3 无障碍

- 支持键盘操作（空格播放、数字键选选项）。
- 对错反馈同时用颜色与图标/文字表达。
- 颜色对比度满足 WCAG AA。

## 8. 里程碑

| 阶段 | 内容                          | 验收标准                             |
| ---- | ----------------------------- | ------------------------------------ |
| M1   | 项目搭建 + 音频播放链路       | 能正确播放钢琴/打击乐采样            |
| M2   | 单音模块完整闭环              | 播放、选项、判定、计分、小结可用     |
| M3   | 音程 + 和弦模块               | 两模块可练，设置生效                 |
| M4   | 旋律模块 + 干扰项算法         | 旋律题可玩，干扰项合理               |
| M5   | 节奏模块                      | 节奏题可播放并选择                   |
| M6   | i18n + 深色/浅色主题          | 中英切换、主题切换生效               |
| M7   | 邮箱 + Google 登录 + 高级功能 | 登录可用，学习计划、统计、错题本上线 |
| M8   | 响应式适配 + PWA + 打磨发布   | 三端体验一致，可离线基础练习         |

## 9. 成功指标

- 单轮练习完成率 ≥ 80%。
- 首屏加载 ≤ 3s（4G），采样懒加载。
- 核心操作（播放 → 答题）≤ 2 次点击。
- 登录转化率 ≥ 15%。
- 登录用户 7 日留存 ≥ 30%。
