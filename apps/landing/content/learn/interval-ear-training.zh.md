音程就是两个音之间的距离——小二度、大三度、纯五度、八度。如果说[练耳](/learn/what-is-ear-training)只有一项核心功夫，那就是它：旋律是音程串起来的，和弦是音程叠起来的，你羡慕的一切「靠耳朵」的能力，底层都是音程识别。好消息是：一个八度里一共就十二个音程，而且它们非常学得会。

## 为什么音程是核心

听一段旋律时，你感知到的其实不是一个个孤立的音，而是音程连成的**形状**——这就是为什么《生日快乐》换到什么调上你都认得出来。音程过关之后，另外两项会明显变容易：[和弦听辨](/learn/chord-identification)，因为和弦的性质就是内部音程决定的；[旋律听写](/learn/melodic-dictation)，因为它无非是音程识别加记忆。先把音程练透，练耳剩下的路都是下坡。

## 十二音程与参考歌曲

给每个音程锚定一首你早就会唱的歌，是最快的入门法：唱起那首歌，音程就跟着出来了。

| 音程   | 参考歌曲（开头两个音）                 |
| ------ | -------------------------------------- |
| 小二度 | 《欢乐颂》(3→4)                        |
| 大二度 | 《两只老虎》(1→2)                      |
| 小三度 | 勃拉姆斯《摇篮曲》开头                 |
| 大三度 | 《When the Saints Go Marching In》开头 |
| 纯四度 | 《婚礼进行曲》开头                     |
| 三全音 | 《Maria》（西区故事）开头              |
| 纯五度 | 《小星星》(1→5)                        |
| 小六度 | 《The Entertainer》开头                |
| 大六度 | 《My Bonnie Lies Over the Ocean》开头  |
| 小七度 | 《Somewhere》（西区故事）开头          |
| 大七度 | 《Take On Me》副歌                     |
| 八度   | 《Over the Rainbow》开头               |

这张表要个性化。参考歌曲的前提是旋律**刻在你自己**的记忆里——不熟《摇篮曲》，就找你歌单里一首开头是小三度的歌换上。

## 三个有效的方法

**参考歌曲法。** 听到陌生音程，心里跟锚点比对：「是《小星星》那个跳吗？不是，更小，接近《两只老虎》？」这建立的是从声音到名称的提取路径。

**模唱。** 答题前先把音程唱出来，平时也从一个给定音起唱各个音程。唱迫使你的内心听觉去**生产**这个距离，而不只是认出它——只认不产的识别是脆的，一紧张就崩。觉得自己五音不全也要唱，越这样越要唱。

**放进语境里听。** 单练音程是手段，音乐才是目的。单个音程稳了之后，练在短旋律里认出它，再在持续低音（drone）上听——后者练的是音的**功能感**，不只是距离感。

## 每天十分钟的流程

1. **热身（2 分钟）:** 从参考歌曲表里挑三四个音程唱一遍，用钢琴软件核对起始音。
2. **刷题（6 分钟）:** 在 [Oh Your Ear](https://app.ohyourear.com) 的音程模块里答题——声音可以反复重放，答错的题会自动收进错题本。
3. **应用（2 分钟）:** 找一首你喜欢的歌，唱出它前三个音程并逐个报名字。

关键是每天。听觉记忆在睡眠中巩固，每天十分钟胜过周六突击一小时。保持习惯的完整方法见[每天怎么安排练耳](/learn/daily-practice-routine)。

## 常见错误

- **一上来十二个全练。** 先练四五个（八度、纯五、纯四、大小三度），练到厌烦，再两个两个地加。
- **只练上行。** 真实旋律有来有回。练习里必须包含下行和同时发声的音程。
- **从不张嘴。** 点对了答案但内心听觉全程沉默，练出来的是做题技巧，不是音乐能力。
- **用单次得分评价自己。** 有些天耳朵就是累。看几周的曲线，别看一次的分数。

## 常见问题

### 一次该练几个音程？

四五个，练到觉得无聊再加两个。小范围上的高正确率，好过全范围上的混乱——混乱正是你要练掉的东西。

### 上行和下行要分开学吗？

混着练，但下行一开始明显更难是正常的，几乎人人如此。下行也有参考歌曲（《Joy to the World》开头就是一条下行音阶）。

### 十二个音程练熟要多久？

每天十分钟的话，多数人两到三个月能稳住常用的八个；三全音和大七度通常最后拿下。

### 答题需要知道音名吗？

不需要。你报的是**距离**，不是音。说出「这是纯五度」，除了十二个名字本身，不需要任何乐理。
