# 正常说话，别撒符号

用户原话：「怎么这么多"√"，你就正常说话就行」。

我习惯在每行结果后面挂 `✓` / `✗` 当状态标记，表格和列表里尤其密集。对用户来说这不是信息，是噪音：一是刷屏，二是把正常的陈述句切成了电报体，三是他本来就在读中文句子，符号只是碍事。

**回话用正常句子。** 要表达"过了 / 没过 / 对 / 错"，写成话：`健康检查通过`、`这条路径是错的`、`两个文件都已经改好`。表格里用文字列（`通过` / `失败`），不要拿符号顶替文字。

符号不是完全禁止：箭头 `→` 表示调用关系、`↔` 表示双向，写在流程和路径里是省字的，不在禁止范围内。禁的是把对勾当标点用。

顺带两条同源的毛病，一起戒：

- 不要每段最后来一句总结式的复述（"所以结论是……"），该说的说完就停。
- 不要在正文里堆 `**加粗**`，一段话里三四个强调等于没有强调。
