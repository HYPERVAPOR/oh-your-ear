# 琴键不跟主题变

**用户已经强调过两次**：界面里只要出现「钢琴键盘」，**白键就必须是白的、黑键就必须是黑的**，切到深色主题也不变。

出错的方式很自然：顺手用了设计令牌 —— `bg-surface`（深色下是深灰）、`bg-ink`（深色下是近白）—— 结果深色主题里黑键变成了白块、白键变成了灰块，键盘反相。用户的原话："黑键就是黑键，白键就是白键，不会因为深色浅色变化"。

正确写法（`apps/landing/src/components/piano-roll.tsx` 的左侧琴键栏）：

```tsx
// 白键恒白、黑键恒黑、键缝是固定的一条细灰线
className="... border-t border-[#d6d3d1] bg-white ..."
{isBlack && <span className="block h-full w-[55%] bg-[#0c0a09]" />}
```

## 边界在哪

- **琴键本身**（键面、黑键短块、键缝）→ 固定色，不跟随主题。
- **卷帘窗网格里"黑键行"的暗底** → 这个**跟随主题**，因为它是 DAW 网格的语汇，不是键盘实体。
- 键盘外框与网格共用一圈边框 → 跟随主题可以接受。

判断方法：问自己"这个像素在物理钢琴上是什么颜色"，是黑白就不许用主题令牌。
