## 背景

原本为无衬线字体（Inter）设计的排版度量，直接套用到等宽字体上会出问题。

## 经过

切到 JetBrains Mono 后：

- 8 处 display 级别的 `font-light`（300）在等宽字体下显得过于纤细脆弱，改为 `font-medium`（500）。
- 原本的负字距（tracking）全部取消——给等宽字体加负字距会破坏它本身存在的网格。
- 数字启用带斜杠的零（slashed zero）。

## 结论

`DESIGN.md` 中的排版规范更新为：

- **One family, everywhere.** Display 与 body 同一套等宽字体栈，层级由字号与字重（display 500 / interface 400–500）承载，绝不靠切换字体。
- Interface text 为 JetBrains Mono at 400/500，**无** tracking 调整（原为 +0.15–0.18px）。

## 原因

等宽字体的字腔与字宽天生一致，300 字重在 display 尺寸下骨架不足；负字距与等宽网格的设计意图直接冲突。
